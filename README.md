# 🤖 AI WorkMate - Frontend

AI WorkMate is a React-based frontend application designed to interact with AI services, manage knowledge bases, and provide an interactive chatbot experience.

---

## 🚀 Features

- 💬 Chat interface for AI interaction
- 📚 Knowledge Base integration
- 📤 Upload documents for AI processing
- ⚡ Fast and responsive UI using React
- 🎨 Styled with Tailwind CSS
- 🔗 API integration using Axios
